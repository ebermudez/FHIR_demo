Note to Record

This is how a consultation note becomes a structured FHIR R4 record in a medical record system: an AI scribe writes the note, the fields are mapped onto Patient, Encounter, Condition, and DocumentReference, and the note is read back unchanged from the server to prove the round trip.

3. Send to record system

      

        "Send to record" creates Patient, Encounter, Condition, and DocumentReference on the
        public HAPI FHIR test server and reads the note back. "Break it" sends a deliberately
        broken version of that same document, so you can see exactly what a rejected
        integration call looks like and why.
