Note to Record

So wird aus einer Konsultationsnotiz ein strukturierter FHIR-R4-Datensatz im Praxisverwaltungssystem: eine KI-Scribe schreibt die Notiz, die Felder werden auf Patient, Encounter und DocumentReference abgebildet, und die Notiz wird unverändert aus dem Server zurückgelesen, um den Roundtrip zu beweisen.
